Mapnik supports all compisiting modes defined in the SVG standard, a few more are available when using the Agg render only.

By default the "src-over" compositing mode is used. A different mode can be set on the <Layer>, <Style> or synmbolizer level.

===  color-burn

`color-burn` darkens the colors of the destination based on the source; the darkening becomes more intense the darker the source is.

image::examples/comp-op/color-burn.png[align=center]


===  color-dodge

`color-dodge` brightens the colors of the destination based on the source; the brightening becomes more intense the brighter the source is.

image::examples/comp-op/color-dodge.png[align=center]


===  darken

`darken` takes the lower value of each of the red, green and blue components of both images.

image::examples/comp-op/darken.png[align=center]
