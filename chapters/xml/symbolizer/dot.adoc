==== DotSymbolizer

Draws simple circular or elliptical circles.

.DotSymbolizer Attributes
[width="100%",options="header,unbreakable",cols="m,d,d,d"]
|====================
| Attribute              | Type          | Default  | Description
| ((height))             | float         | 0.0      | Ellipse width
| ((width))              | float         | 0.0      | Ellipse height
| ((fill))               | color         | gray     | Fill color
| ((opacity))            | float         | 1.0      | Fill opacity
| ((comp-op))            | string        | src-over | see <<Compositing>>
|====================
