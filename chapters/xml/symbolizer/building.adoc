==== BuildingSymbolizer

The ((`<BuildingSymbolizer>`)) renders polygons in a very simple pseudo-3D fashion. The given fill color us used for the "roof", while its individual red, green and blue values are multiplied by 0.8 to create a more darkened tone for the "walls"

.BuildingSymbolizer Attributes
[options="header,unbreakable"]
|===
| Attribute      | Value      | Default | Description
| <<example-buildingsymbolizer-fill,((`fill`))>>         | CSS color  | gray |
| <<example-buildingsymbolizer-fill-opacity,((`fill-opacity`))>> | float       | 1.0 |
| <<example-buildingsymbolizer-height,((`height`))>>       | float      | 0 |
| ((comp-op)) | string | src-over | See <<Compositing>>, works with Cairo Graphics only right now, for Agg support see http://github.com/mapnik/mapnik/issues/1355[Mapnik Issue #1355].
|===
