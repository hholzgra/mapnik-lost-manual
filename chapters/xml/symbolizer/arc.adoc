==== ArcSymbolizer

[NOTE]
====
The ArcSymbolizer is a recent experimental addition and is not yet available in released Mapnik versions. It supports the AGG, Cairo and SVG renderer backends.
====

The ArcSymbolizer can draw full circles and partial arcs. The arc center point is defined by the layer geometry while radius, start and end angle in case of arcs, and visual styling are defined by the symbolizer attributes.

The motivation to create the ArcSymbolizer was to be able to render sea navigation lights in a way similar to how the custom OpenSeaMap renderer does it, but can also be used for other purposes like e.g visualization of camera viewing areas, or even to add simple pie charts to a map.

Arcs are drawn clockwise from the `start-angle` to the `end-angle`, angle values are given in degrees with 0° / 360° being north / up. As the angles default to 0° and 360° a full circle is drawn when no angle values are given explicitly.

The ArcSymbolizer allows to style how the arc is filled and what strokes to use for the actual ark, and for the radius lines connecting the end points of the arc to the center point. Adding a textual label is also possible, the text will be drawn curved along the arc when the arc is longer than the text; otherwise the text will be drawn facing outwards from the arc center.

The `stroke-*` attributes style both the arc line and the radius lines. Each of them can be overridden separately for just the arc line by an `arc-stroke-*` attribute, and for just the radius lines by a `radius-stroke-*` attribute. The radius lines are drawn whenever `stroke` or `radius-stroke` is set; to draw an arc line without radius lines, use `arc-stroke` instead of `stroke`.


[NOTE]
====
The attribute names are not final yet.
====

.ArcSymbolizer Attributes
[width="100%",options="header,unbreakable",cols="m,d,d,d"]
|====================
| Attribute                 | Type       | Default      | Description
| <<example-arcsymbolizer-angles,((radius))>>       | float | 0 | Radius in pixels
| <<example-arcsymbolizer-angles,((start-angle))>>  | float | 0 | Starting arc angle, 0° being north/up
| <<example-arcsymbolizer-angles,((end-angle))>>    | float | 360 | Ending arc angle, arc is drawn clockwise from start to end
| <<example-arcsymbolizer-fill-stroke,((fill))>>    | color | none | Circle / arc fill color
| ((fill-opacity))          | 0.0 - 1.0  | 1            | ... TODO ...
| <<example-arcsymbolizer-fill-stroke,((stroke))>>  | color | none | Color of both the arc line and the radius lines
| ((stroke-width))          | float      | 1            | Width of both the arc line and the radius lines
| ((stroke-opacity))        | 0.0 - 1.0  | 1            |
| ((stroke-dasharray))      | number list | none        | Dash pattern for both the arc line and the radius lines
| ((stroke-dashoffset))     | float      | 0            |
| <<example-arcsymbolizer-radius-lines,((arc-stroke))>> | color | stroke | Color of the arc line only
| ((arc-stroke-width))      | float      | stroke-width | Width of the arc line only
| ((arc-stroke-opacity))    | 0.0 - 1.0  | stroke-opacity |
| ((arc-stroke-dasharray))  | number list | stroke-dasharray | Dash pattern for the arc line only
| ((arc-stroke-dashoffset)) | float      | stroke-dashoffset |
| <<example-arcsymbolizer-radius-lines,((radius-stroke))>> | color | stroke | Color of the radius lines only
| <<example-arcsymbolizer-radius-lines,((radius-stroke-width))>> | float | stroke-width | Width of the radius lines only
| ((radius-stroke-opacity)) | 0.0 - 1.0  | stroke-opacity |
| <<example-arcsymbolizer-radius-lines,((radius-stroke-dasharray))>> | number list | stroke-dasharray | Dash pattern for the radius lines only
| ((radius-stroke-dashoffset)) | float   | stroke-dashoffset |
| <<example-arcsymbolizer-text,((text))>> | expression | none | Label, bent along the arc or placed perpendicular to it
| ((text-face-name))        | string     |              | Font face for the label, required with text
| ((text-fontset-name))     | string     |              | Fontset alternative to text-face-name
| ((text-size))             | float      | 10           |
| ((text-fill))             | color      | black        | Text color
| ((text-opacity))          | 0.0 - 1.0  | 1            |
| ((text-halo-fill))        | color      | white        |
| ((text-halo-radius))      | float      | 0            |
| ((text-halo-opacity))     | 0.0 - 1.0  | 1            |
| ((text-character-spacing)) | float     | 0            |
| ((text-transform))        | none, uppercase, lowercase, capitalize, reverse | none | Case conversion applied to the label text
| ((text-font-feature-settings)) | string | none        | Comma separated list of https://drafts.csswg.org/css-fonts-3/#propdef-font-feature-settings[OpenType typographic features]
| <<example-arcsymbolizer-text,((text-offset))>> | float | 2 | Radial gap between the arc line and the label
|====================
