[#map-background-image]
==== `background-image` attribute

Sets a background image for the map. The image is not scaled to the actual map output size, if the two sizes do not match it is either cropped or tiled.

[#map-buffer-size]
==== `buffer-size` attribute

Also takes features this many pixels outside of the actual map area into account. A feature that lies slightly outside of the actual tile area, but renders a symbol that would still partially be visible inside the tile -- e.g. a 32x32 pixel marker for a feature just one pixel outside the tile. By extending the buffer size to a value of 16 here about half the symbol would still be rendered. This is needed to not have symbols cut at tile borders.

The setting can be overridden on a per-layer basis later, e.g. for a marker layer it should be set to at least half the width / height of a marker while for a line or polygon symbolizer it would only need to be about half as wide as the stroke. An even larger buffer would be needed for text symbolizer labels.

[#map-minimum-version]
==== `minimum-version` attribute

Specifies the minimum Mapnik version needed to process this stylesheet.

Requires a three part version number, so `3.0.0` works but `3.0` or just `3` doesn't. (See also https://github.com/mapnik/mapnik/issues/4369)
